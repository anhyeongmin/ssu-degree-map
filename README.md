# SSU DegreeMap

숭실대학교 졸업사정표의 익숙한 표 구조를 유지하면서, 각 요건의 부족 원인·다음 행동·공식 근거를 함께 보여주는 시연용 MVP입니다.

## 주요 기능

- 졸업요건별 기준·인정 현황·부족분·판정 표시
- 행 선택 시 판정 이유와 공식 근거 확인
- 졸업확정신고 등 비학점·행정요건 반영
- 전공선택 학점 부족 시나리오 전환
- 입력 변경 후 졸업판정 즉시 재계산

## 로컬 실행

```bash
npm ci
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 배포

`main` 브랜치에 변경사항이 올라가면 GitHub Actions가 정적 사이트를 빌드해 GitHub Pages에 자동 배포합니다.

> 현재 데이터와 규칙은 공모전 시연을 위한 익명화·가공 예시이며, 실제 u-SAINT와 연결되어 있지 않습니다.
